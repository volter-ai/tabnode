The original `sqlite3.wasm` has SHA-256
`2ee8f3dab694532afc8840e07703127287662d08b74e6ff50491ce63f00d5752`
and Git blob `2ea991b7bc2ad85a684f012a793985b0c5b9a721`, identical to

at that package's npm provenance commit. The package archive is pinned by
`package-lock.json`. The wrapper and TypeScript declarations are Apache-2.0;
the engine embeds the original Wasm body and calls its C API directly.

The companion generated `src/bin/sqlite3.mjs` identifies SQLite source
`2026-07-24 19:02:57 bf7c7f30031888f4e796e429ab3978879485813aaca6f641c7b33e4e09459bcc`
and Emscripten SDK 5.0.5. Corresponding SQLite source and its Wasm build are at
<https://sqlite.org/src/info/bf7c7f30031888f4e796e429ab3978879485813aaca6f641c7b33e4e09459bcc>
and `ext/wasm/` in that source. The npm source repository preserves its package
assembly and `scripts/build-sqlite3-wasm.sh`. These source locations describe
the shipped input; this engine does not claim to have rebuilt upstream Wasm.

[`2bbbfaf8cc769109361ba29b55f5647a43988b14`](https://github.com/vercel-labs/just-bash/tree/2bbbfaf8cc769109361ba29b55f5647a43988b14/packages/just-bash).

`e334360d00299c0c01ab9251003045d90b27d1f87ad9e8a4b9513563e7ac68fe`.

the Python and QuickJS loaders from that entry. The supplier's optional CPython
vendor files are not inputs of this browser entry. The browser entry includes
RE2JS and the `file-type` JavaScript dependency graph. Their versions in the
first table are pinned by `pnpm-lock.yaml` at the upstream source above;
`@tokenizer/token` provides types, with no JavaScript body incorporated by this graph.
